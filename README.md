# P.H.Tools — Kurdish Sorani Construction Store

A responsive front-end e-commerce website for P.H.Tools, built in plain HTML/CSS/JavaScript.

## Included
- Kurdish Sorani (RTL) interface
- Uploaded Rabar_037 font
- Uploaded P.H.Tools logo
- Uploaded hero banner
- Product grid with categories
- Search and sorting
- Shopping cart with localStorage
- Checkout form demo
- Responsive mobile navigation

## Run
Open `index.html` in a browser.

## Important
The checkout is currently a front-end demo. To accept real orders/payments, connect the form and product data to your backend/database/payment provider.

Replace the placeholder phone/email/address in `index.html` with the store's real information.
